> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует компоненты WinDivert как инструменты повышенного риска или хакерские средства. В результате файл может быть удалён и отправлен в карантин. Название обнаружения обычно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса или выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше указать исключение для папки. При недостаточном понимании этих параметров рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите конкретного поставщика услуг, а не вариант "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`; провайдер Cloudflare может оказаться заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic следует включить в его настройках "Транзит запросов". Если параметр выключен, настройка Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Barbnorescue/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, это действие не требуется

4. Извлеките архив в каталог, в пути к которому нет кириллических символов и специальных знаков

5. Запустите подходящий файл
    * Чтобы определить работающую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки выбранной стратегии в автозапуск перейдите в **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Этот способ подходит для проверки разных вариантов обхода. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - отображение состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других приложений, работающих с UDP и TCP-портами выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** - настройка режима обхода для ресурсов из `ipset-all.txt`.  
  Это бывает полезно при проверке ресурса, который без zapret открывается, а с ним перестаёт работать.  
  В скобках выводится текущее состояние:
    - `none` - ни один IP не проверяется
    - `loaded` - проверяется принадлежность IP списку
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или выключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена используемого фейка на другой из каталога `bin`
  - **`Update IPSet List`** - получение актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** - ручной поиск обновлений
  - **`Run Diagnostics`** - проверка распространённых причин, из-за которых zapret не запускается или не работает.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность клиента после внезапного сбоя
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы

### После запуска `general*` нет никакой реакции

- При запуске стратегии отдельным bat-файлом, а не через service, процесс обхода winws.exe должен появиться в панели задач.  
Если этого не произошло, ознакомьтесь с [#522](https://github.com/Barbnorescue/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте содержимое открытого блокнота целиком
  - Найдите появившийся файл `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните изменения и снова проверьте подключение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Работа не гарантируется. При отсутствии результата используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Barbnorescue/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегия, которая работает сейчас, позже может перестать работать.**
> После обнаружения определённая стратегия иногда теряет эффективность, даже если раньше успешно обходила блокировку.
> В этом репозитории есть несколько разных вариантов. Если готовые настройки не помогают, создайте собственную стратегию на основе одной из них, изменив её параметры.
> Описание параметров доступно в [документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте отсутствие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Проверьте остальные варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Barbnorescue/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите компьютер
- Откройте `service.bat` -> `Remove Services`
- Затем выберите `service.bat` -> `Run Diagnostics`; при обнаружении ошибок исправьте их и в конце ответьте Y
- Удалите каталог zapret
- Скачайте свежую версию со [страницы релизов](https://github.com/Barbnorescue/zapret-discord-youtube/releases), архив вида `zapret-discord-youtube-...`
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК"
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- По очереди запускайте разные скрипты `general`. После каждого проверяйте интернет-ресурсы: если они не открываются, закройте программу через значок замка в панели задач и попробуйте другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. В противном случае обход может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция по этому случаю находится [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide)

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы в командной строке Windows, открытой через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Дополнительные сведения есть в [#251](https://github.com/Barbnorescue/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён и настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, появился ли доступ к приложению Discord после очистки.
- Откройте веб-версию по адресу https://discord.com/app. Если браузерная версия работает, используйте её.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Также см. [#252](https://github.com/Barbnorescue/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Barbnorescue/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игры используют разные сетевые схемы, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не дало результата, дополнительно активируйте `ipset any`

Учтите, что режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Barbnorescue/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему нет

- Опишите её [в issue](https://github.com/Barbnorescue/zapret-discord-youtube/issues)

## 🗒️Добавление других адресов

В список обхода можно включить дополнительные домены, IP-адреса и подсети:
- **`list-general-user.txt`** - домены; соответствующие поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP сети находится в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
